# Sideleaf

A small desktop Markdown editor for your words and your files.

Sideleaf begins as a fresh implementation using Electrobun, Cottontail, and system
webviews. Mature JavaScript libraries can provide editing and Markdown rendering.
Margin is a product reference; its implementation is not part of this project.

[PLAN.md](PLAN.md) records the product direction, architecture, staged scope, and
prototype acceptance criteria. This repository currently contains the project plan;
there is no runnable editor or release artifact yet.

The website is [sideleaf.xyz](https://sideleaf.xyz), maintained separately in
[kortexa-ai/sideleaf](https://github.com/kortexa-ai/sideleaf).
