# Sideleaf app icon

Generated on 2026-09-07 using [fal.ai FLUX 1.1 Pro](https://fal.ai/models/fal-ai/flux-pro/v1.1/api).
The original 1024 × 1024 PNG is `icon-source.png`. `icon-generation.json` records the
exact prompt, model, seed, and settings. The design is an ivory paper sheet with a
folded corner and a green ginkgo leaf on a forest-green tile.

`scripts/build-icons.mjs` crops the generated tile, supplies alpha at its outside
corners, and creates a seven-size `icon.ico` for Windows plus a padded `icon.iconset`
for macOS. `icon.png` is the full-resolution transparent tile.
Generation credentials are not stored here. The app serves no assets from fal.ai.
