# Sideleaf 0.1.12

Issue: https://github.com/kortexa-ai/sideleaf.desktop/issues/84

Open a folder from the command line with `sideleaf DIRECTORY` (#82) and, on
macOS, from the Dock icon, Finder or `open -a` (#79). On macOS, show a Ziblet
button in the toolbar when Ziblet and its notes folder are present, and offer
Get Ziblet in the menu (#83). Release acceptance follows the native macOS and
Windows procedures in `internal/TESTING.md` and `docs/releasing.md`.

Execution and release evidence belong in the linked issue and Project 4.
